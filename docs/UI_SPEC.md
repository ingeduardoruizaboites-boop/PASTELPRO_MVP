# PastelPro · Especificación UI

## Identidad visual
- Cálida, premium, femenina sin infantil.
- NO: contable, bancaria, ERP, calculadora científica.

## Paleta base
- Fondo: crema cálido.
- Superficies: blanco.
- Principal: cacao.
- Acento: berry discreto.
- Semánticos: verde éxito, ámbar advertencia, rojo error.

## Tipografía
- Título principal: grande, semibold.
- Título de sección: mediano, semibold.
- Información: regular.
- Datos importantes: semibold/bold.
- Resultado principal: muy grande.

## Navegación
Barra inferior fija con 5 áreas:
1. Inicio
2. Recetas
3. Pedidos
4. Compras
5. Más

## Reglas
- Una decisión a la vez.
- Formularios largos por pasos.
- Altas rápidas en Bottom Sheet.
- Estados explícitos: normal / presionado / deshabilitado / cargando / éxito / advertencia / error.
- Animaciones 180–250 ms, funcionales.
- No depender solo del color.
- Sin botones sin función. Sin textos técnicos.
